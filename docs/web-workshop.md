# Browser workshop

Run `pnpm install --frozen-lockfile` and `pnpm start` in a development checkout. Open the local URL printed in the terminal. For offline use, run `pnpm build` and open `dist/character-view.html` in a WebGL 2 browser.

Choose a starter in **Forms**. Edit its parts, paint, outfits and poses, then export the character as a GLB. Open it in `dist/play-model.html` to inspect its surfaces, switch outfits and play animations. Use **Export AI request** and **Load proposal** to exchange files with an agent.
