# Phase 9-4 · 3D reference fitting and head families

Each comparison uses the same seeded adult and source meshes in Chrome and Electron. Screenshot filenames refer to the local `.reference-cache/phase9-4/` directory. Open `contact-sheet.png` to see all 67. Reference assets and images containing practice meshes stay local.

Build both workshops before running `pnpm --filter @irudd/desktop qa:reference-parity`. Append `body`, `head`, `marks`, `family` or `studio` for a focused run. The full run checks the hardware renderer on both sides, exports the studio head and standalone ponytail, undoes and redoes an applied edit, and opens the saved character in a fresh desktop project.

The comparisons use the official MHR v1.0.1 neutral and six corresponding bodies. Fetch the archive with `node scripts/local-references.mjs --fetch`. Extract `assets/lod1.fbx` to `.reference-cache/mhr/lod1.fbx`. Prepare the rest example, benchmark bodies and registered family neutral from the project root.

```sh
blender -b --factory-startup --python-exit-code 1 --python scripts/export-mhr-reference.py -- .reference-cache/mhr/lod1.fbx examples/mhr-reference.glb
python scripts/human-benchmark/build-targets.py .reference-cache/mhr
python scripts/family-transfer/build-neutral.py .reference-cache/mhr .reference-cache/phase9-4/mhr-neutral.glb
```

On an RTX 5070 Ti, two complete paired runs took 13 and 15 minutes while other desktop verification was running.

The fixture generator makes the other meshes from the native adult, including the open face scan and the transformed, skinned glTF. [Local reference files and rebuild commands](../scripts/local-references.mjs) · [MHR v1.0.1 source](https://github.com/facebookresearch/MHR/releases/tag/v1.0.1)
